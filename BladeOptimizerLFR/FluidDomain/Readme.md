# How is the Fluid Domain Generated?

The Fluid Domain is created by computing the difference of a cylinderical **duct** and the **solid domain (the pump itself)**

The `vtk` files could be imported to Ansys Fluent and other traditional CFD softwares in for futher processing. All the surface has a related integer in the `vtk` files.

`BoundaryID_Map_20250920_185607.json` contains the nomenclature of each boundaries.
